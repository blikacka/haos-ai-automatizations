# AI automatizace

![Supports amd64 Architecture][amd64-shield]
![Supports aarch64 Architecture][aarch64-shield]

Doplněk pro Home Assistant OS, ve kterém si s umělou inteligencí (OpenAI Codex
přihlášený vaším účtem ChatGPT) povídáte česky a ona za vás vytváří automatizace,
upravuje YAML konfiguraci a zprovozňuje hardware (např. USB Modbus relé).

Každá změna je předem zálohována, po změně ověřena (`check_config`) a uložena
do historie verzí, ze které ji lze jedním kliknutím vrátit.

Podrobný návod najdete v záložce **Dokumentace** (soubor [DOCS.md](DOCS.md)).
